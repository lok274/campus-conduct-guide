ATTENDANCE / 考勤管理

每次留堂，都有清楚紀錄。

安排、出席、豁免和改期放在同一份紀錄，日後可查閱原日期、原因與操作者。

  1. 01

    手動安排

    選班別、學生及留堂日期，填寫備註。同一學生同日只保留一筆有效留堂。

  2. 02

    核對出席

    登記待出席、已出席或缺席。未來的留堂可預先安排，到當日再核對出席。

  3. 03

    記錄豁免

    選「已豁免」並填寫原因，保留有效紀錄；需要時可再修改出席狀態。

  4. 04

    改期留痕

    按「改期」填新日期及原因；歷程保留改期前後資料，方便交接與核對。

列表可按日期、班別、學生及狀態篩選，每頁顯示 50 筆。

ONE SCHOOL / 一套系統

從課堂到校務，
讓紀錄互相接得上。

老師按獲授權的班別操作；管理員集中維護帳號、名冊與學期設定。

01 / 操行

操行管理

按班別及學生登記獎懲，查閱紀錄、分數與歷程，分開核對勤到、勤學及守規。

登記 → 核對 → 查閱
02 / 家課

家課收交

建立家課，逐人登記收交與備註，核對欠交確認；已保存的家課說明可隨時查閱。

欠交次數與扣分分開處理
03 / 勤學

勤學評核

按學期填寫課堂表現、平均分及格與否及出席率，另可手動登記額外逾期扣分。

按班批次儲存
04 / 考勤

考勤與遲到留堂

登記準時、缺席及遲到，核對應回校時間與遲到分鐘；另以手動流程安排留堂。

支援 CSV 拍咭資料上載
05 / 報表

報表中心

集中查閱操行、勤學及勤到報表，包括學期總結與優異名單，按權限範圍輸出 CSV 或列印。

保留正在查看的報表分頁
06 / 管理

共用管理

維護學年學期、班級學生、老師、帳號及班別權限，並透過本機備份保存資料。

名冊匯入前先預覽核對

DAILY ROUTINE / 每天的使用方式

先選學期，
再處理手上的事。

跟著指南逐步操作 →
  1. 1

    登入並選擇學年、學期

    確認頁首範圍，核對所選學期的開始及結束日期。

  2. 2

    在對應模組選班別及學生

    按任務進入操行、家課、勤學或考勤，老師只操作獲授權班別。

  3. 3

    核對內容後儲存

    離開未儲存表單時，可選儲存、放棄或取消。儲存失敗時保留輸入供核對。

  4. 4

    查閱歷程、輸出報表

    需要核對修改時查看歷程；需要整理資料時前往報表中心。

BEFORE YOU START / 常見問題

使用前，先了解這幾點。

這個網站可以直接登記學生資料嗎？

此網站提供功能展示及操作指南。實際登記請開啟電腦上的完整系統，登入後再選擇學期與班別。

留堂會按遲到次數自動安排嗎？

目前採手動安排。老師在「考勤管理 → 遲到留堂紀錄」新增學生與日期，再登記出席狀態、豁免或改期。

「豁免」和「註銷」有甚麼分別？

獲批准不用參加留堂時，選「已豁免」並填原因，保留一筆有效安排。誤建或需要撤銷紀錄時，填原因註銷；兩者都保留歷程供查閱。

學生轉班後，舊紀錄會搬到新班嗎？

既有紀錄保留固定學期及原班籍。轉班後查閱或修改舊紀錄，仍按原班別的權限處理。
